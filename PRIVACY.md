# Privacy Policy: Shortcuts for SoundCloud

*Last updated: October 27, 2026*

## Summary

Shortcuts for SoundCloud is a browser extension that adds keyboard shortcuts and a now-playing panel for soundcloud.com. It does not collect, store, or transmit any personal data. Everything it does happens inside your browser.

## What the extension accesses

- **The soundcloud.com tab.** The extension reads the player bar on soundcloud.com (track title, artist, artwork, playback position, like and repost state) and clicks the player's own controls on your behalf. It does not read any other part of the page and has no access to other websites.
- **Track waveform and artwork.** To draw the waveform and show artwork in the now-playing panel, the extension fetches the same waveform file and artwork image that soundcloud.com itself loads for the current track, from SoundCloud's servers. No other network requests are made.

## What is stored

- **Your settings** (shortcut behavior, notification and panel preferences) are stored using the browser's extension storage. If you are signed in to your browser, the browser may sync these settings between your devices. The developer never receives them.
- **The current track** (title, artist, artwork, playback position) is kept in the browser's session storage so the panel and notifications can show it. It is cleared when the browser closes.

## What is not collected

The extension has no analytics, no telemetry, no accounts, no advertising, and no servers operated by the developer. It does not collect your listening history, your SoundCloud account details, your browsing activity, or any identifiers.

## Permissions

- **Access to soundcloud.com**: to control the player and read what is playing.
- **Scripting**: to connect to a soundcloud.com tab that was already open when the extension was installed or updated.
- **Storage**: to save your settings and the current track.
- **Notifications**: to show an optional notification when a new track starts.

## Open source

The complete source code is public at https://github.com/jgentes/soundcloud-shortcuts, so these statements can be verified.

## Changes

If the extension's data practices ever change, this page will be updated and the change will be noted in the release notes.
